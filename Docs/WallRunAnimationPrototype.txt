LEFT WALL RUN - ANIMATION EXPERIMENT

Asset: /Game/Showcase/AnimationExperiments/WallRun/AA_WallRun_Left_Prototype
Source: /Game/Characters/Mannequins/Animations/Manny/MM_Run_Fwd

Separate Manny animation sequence; no existing animation, plugin source,
animation Blueprint or gameplay binding was replaced. No Git commits.

The duplicate removes forward root motion, adds a 16-degree body lean away
from a left wall, reshapes ankle paths using the source's foot-lift timing,
solves knee and elbow positions, adjusts sole orientation, rebalances the
hands, and closes the first/last pose. IK foot/hand markers follow the result.
The notional wall is component-space +X, character left with mesh yaw -90.

This is a first-pass animation prototype, not a finished gameplay animation.
Wall clearance, sole contact, knee direction, hand poses, speed matching and
entry/exit blends require visual and gameplay review before plugin migration.
